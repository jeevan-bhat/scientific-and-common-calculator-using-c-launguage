# 🧮 Calculator using Classes in C++

A simple **C++ Calculator** built using **Object-Oriented Programming (OOP)** concepts.
This program performs basic arithmetic operations — **Addition, Subtraction, Multiplication, and Division** — using a class-based approach.

---

## 📌 Features
- Class-based design for better code organization.
- Supports:
  - Addition
  - Subtraction
  - Multiplication
  - Division (with zero-check)
- Input validation for safe execution.
- Works with both integers and floating-point numbers.

---

## 🛠️ Technologies Used
- **Language:** C++
- **Concepts:** Classes, Methods, Encapsulation, Input Validation
